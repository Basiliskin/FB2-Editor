# Release notes 1.5.4 (build 28)

Play Console limit: 500 characters per language.

## en-US

Improve with AI: you can now set how much text is sent in one request for each provider (Chunk limit), so long passages go out in fewer requests with newer models.
If the model's answer is cut off, the app now says so, retries in smaller parts, and tells you what to change.

## ru-RU

Улучшение с ИИ: для каждого провайдера можно задать, сколько текста отправляется за один запрос (лимит фрагмента), поэтому длинные отрывки уходят меньшим числом запросов с новыми моделями.
Если ответ модели оборвался, приложение сообщает об этом, повторяет запрос частями и подсказывает, что изменить.
