# Release notes 1.5.7 (build 31)

Play Console limit: 500 characters per language.

## en-US

Story map: Improve with AI now proposes places, events, lore and tie labels. Each proposal is reviewed before it reaches the map; ties are grouped under their place and can be filtered.
Translate: whole-section translation with names, context from earlier pairs, undo, and a per-part review with accept, reject and retry.
Editor: slimmer app bar with an overflow menu; the format bar shows only while you edit a paragraph.

## ru-RU

Карта истории: «Улучшить с ИИ» предлагает места, события, лор и подписи связей. Каждое предложение проверяется до попадания на карту; связи сгруппированы по местам, есть фильтры.
Перевод: перевод всего раздела с именами, контекстом прошлых пар, отменой и проверкой по частям: принять, отклонить, повторить.
Редактор: компактная панель и меню; панель форматирования видна только при правке абзаца.
